Flutter 3.50으로 올린 뒤 다국어 문서의 golden 테스트가 깨지거나 `TextWidthBasis.longestLine`을 기준으로 잡은 카드 폭이 달라졌다면 `U+00AD` soft hyphen을 확인해야 한다. 단순 텍스트를 쓰는 앱은 기본 동작을 받아들여도 되지만, 번역 문자열·PDF 미리보기·스크린샷 테스트처럼 줄바꿈 결과가 계약인 화면은 `Hyphens.hidden`을 적용할지 결정해야 한다.

## 무엇이 바뀌었나

soft hyphen은 단어를 어디에서 나눌지 표시하지만 평소에는 보이지 않는 문자다. Flutter 3.50부터 네이티브 플랫폼에서는 실제 줄바꿈이 일어날 때 하이픈을 그린다. 웹은 3.50 stable에서 아직 보이지 않는 경로가 남아 결과가 다를 수 있다.

| 상황 | Flutter 3.50 결과 | 판단 |
| --- | --- | --- |
| 일반 `Text`가 soft hyphen에서 줄바꿈 | `-`가 보임 | 자연스러운 새 동작을 유지 |
| `TextWidthBasis.longestLine` 사용 | 하이픈 폭만큼 측정값이 달라질 수 있음 | 레이아웃 golden 재검토 |
| 기존 golden 이미지에 soft hyphen 포함 | 픽셀 차이로 실패 | 기준 이미지 갱신 또는 숨김 |
| `TextField`, `SelectableText` | 선택형 옵션이 없음 | 문자열 정규화나 버전별 테스트 |

## 기존 화면을 유지하는 설정

번역 서버가 넣은 soft hyphen을 화면에 표시하면 안 되는 제품이라면 텍스트 위젯에만 숨김 옵션을 준다. 이 설정은 줄바꿈 위치까지 없애는 것이 아니라, 줄바꿈 기회를 남긴 채 글리프만 숨긴다.

```dart
Text(
  localizedDescription,
  hyphens: Hyphens.hidden,
  textWidthBasis: TextWidthBasis.longestLine,
)
```

`RichText`와 `TextPainter`에도 같은 선택을 전달할 수 있다. 단어 분할을 시각적으로 알려야 하는 화면이면 `Hyphens.manual` 기본값을 유지한다.

커스텀 `TextStyle` 프록시가 `getParagraphStyle`을 재정의한다면 3.50에서 새 named parameter를 받아야 컴파일된다. 전달을 생략하면 상위 API의 설정을 잃을 수 있으므로 아래처럼 그대로 넘긴다.

```dart
@override
ui.ParagraphStyle getParagraphStyle({
  TextAlign? textAlign,
  TextDirection? textDirection,
  double? maxLines,
  StrutStyle? strutStyle,
  Hyphens? hyphens,
}) {
  return super.getParagraphStyle(
    textAlign: textAlign,
    textDirection: textDirection,
    maxLines: maxLines,
    strutStyle: strutStyle,
    hyphens: hyphens,
  );
}
```

## golden 테스트와 출시 점검

실패한 golden을 무조건 갱신하면 플랫폼 차이를 놓친다. `flutter test --update-goldens` 전에 fixture에 `\u00AD`가 들어 있는지 검색하고 Android·iOS와 Web 결과를 분리한다. 3.50에는 줄 끝이 아닌 위치에도 하이픈이 보이거나 폭 밖으로 살짝 나오는 알려진 문제도 있다.

- [ ] 번역 fixture와 API 응답에 `U+00AD`가 있는지 확인했다.
- [ ] `Text`, `RichText`, `TextPainter` 중 실제 그리는 주체를 찾았다.
- [ ] native golden과 Web golden을 같은 기준 이미지로 비교하지 않았다.
- [ ] `TextWidthBasis.longestLine`을 쓰는 부모의 폭·overflow를 다시 확인했다.
- [ ] `TextField` 계열은 `hyphens` 옵션이 없다는 조건을 기록했다.

모든 텍스트에 `Hyphens.hidden`을 일괄 적용할 필요는 없다. 하이픈 표시가 의미 있는 문서에는 기본값을 두고, 레이아웃과 golden이 이전 픽셀에 묶인 화면에만 정책을 고정한다. 확인 기준은 2026년 11월 13일 Flutter 3.50 공식 변경 문서다.
